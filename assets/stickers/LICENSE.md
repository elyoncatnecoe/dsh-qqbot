# 内置表情包

本目录下的图片为本项目作者自绘，随 MIT 许可证一同分发（见仓库根目录 `LICENSE`）。

可用标签（即文件名，`qqbot_sticker` 按标签匹配，也接受中文别名）：

| 文件 | 标签 | 常见中文对应 |
|---|---|---|
| fine.png | fine | 好 / 可以 / 行 |
| mocking.png | mocking | 嘲讽 / 阴阳 / 鄙视 |
| pray.png | pray | 祈祷 / 拜托 / 求 |
| sleeping.png | sleeping | 睡 / 困 / 晚安 |
| thinking.png | thinking | 思考 / 想 / 琢磨 |
| tired.png | tired | 累 / 疲惫 / 麻了 |
| wonder.png | wonder | 疑惑 / 奇怪 / 问号 |

想换成自己的图：把图片放进任意目录，配置 `sticker.dir` 指向该目录即可（文件名同样作为标签）。
