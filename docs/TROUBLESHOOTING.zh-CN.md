# 排错手册

按症状和错误码查。多数问题在开放平台侧，不在插件。

## 一句话对照

| 症状 | 最可能的原因 |
|---|---|
| 装好、扫码成功，但**发消息完全没反应** | 事件订阅没勾，或你的号不在沙箱测试人员里 |
| 群里 @ 了也没反应，私聊正常 | 群聊 `@` 事件没订阅（`GROUP_AT_MESSAGE_CREATE`），或机器人不在该群 |
| 回复很慢 | 群聊没有流式，等多轮生成完才发；或模型本身慢 |
| 语音/表情包发不出，报「被动回复时间或者次数超过限制」 | 媒体消息必须在窗口内：群 5 分钟、私聊 60 分钟 |
| 机器人重复回答、消息发两遍 | 同一个 appId 同时启用了两个插件（官方版 + 本包），关掉一个 |
| 换音色没反应 | 你不是主人，且主人没 `/voice open` |

## 错误码

| 错误码 | 含义 | 怎么办 |
|---|---|---|
| `40034105 主动消息失败, 无权限` | 平台已关闭群主动推送 | 无法绕过。群侧只能被动回复，只能私聊主动推送 |
| `40034123 不支持召回消息` | `is_wakeup` 召回不被支持 | 别用，平台没这能力 |
| `40034005` / 「被动回复时间或者次数超过限制」 | 超出 5 分钟/4-5 次窗口 | 让用户重新发一条消息触发；媒体消息尤其受限 |
| `11253 应用无接口访问权限` | 该接口未对本机器人开放（如群成员列表） | 无解，换思路 |
| `11703 机器人不是群管理员` | 入群申请等接口需要管理员 | 在群设置里把机器人设为管理员 |
| `11255 请求的资源不存在(用户/群已注销)` | openid 失效（换过 appId 后旧 openid 全部作废） | 重新让用户在群里 @ 一次，拿到新 openid |
| `11241 请求头 Authorization 参数格式错误` | token 空或拼错 | 检查 AppID/AppSecret 是否匹配 |
| `304076 req err` | 单聊 openid 与当前 appId 不匹配 | 同上，重新触发一次消息 |

## 收不到任何消息时，按顺序查

1. **事件订阅**：q.qq.com → 开发设置 → 事件订阅 → 勾「群聊 @ 消息」和「C2C 消息」。**不勾不会报错，只是永远收不到。**
2. **沙箱测试人员**：机器人未上线时，只有名单里的 QQ 号能触发。把你的号加进去。
3. **机器人进群了吗**：群设置 → 群机器人 → 确认它在列表里。
4. **群里要 @**：不 @ 平台不推事件，这是规则。
5. **是不是两个插件同时跑**：同一个 appId 开两条 WebSocket 会互相抢事件。

## 语音相关

- **换音色只对当前会话生效**，群里和私聊各自独立；要全局改就改配置 `voice.voiceId` + `voice.semitones`。
- **变调失真**：超过 ±6 半音会明显发闷，建议范围内。
- **语音太长发不出**：默认单条限制 300 字（`voice.maxChars`）。
- **没有 DEEPSEEK_API_KEY**：TTS 走 DeepSeek 官方接口（按字符计费），必须用官方 Key。插件按顺序找：环境变量 `DEEPSEEK_API_KEY` → `~/.dsh/.credentials.yaml`。在 DSH 里登录 DeepSeek 账号即可自动具备；也可以自己 export 环境变量。**只影响语音，文字聊天不需要它。**
- **识图报 `no adapter registered for provider "..."` / 「模型看不了图」**：`vision.provider` / `vision.model` 没填对。要填一个在 DSH 模型列表里标注支持图片输入的模型；provider 名字取决于你自己接的网关，不是固定的。

## 表情包相关

- 报「表情目录里没有可用图片」→ `sticker.dir` 指错了，或目录里没有 png/jpg/gif/webp。
- 想加自己的图：文件名就是标签，例如 `happy.png` 之后 `/`或模型就能用 `happy`。

## 记忆相关

- 记忆文件在 `~/.dsh-qqbot-plus/memory/`，可以随时删。
- 群里记忆很稀疏是正常的：它只记得被 @ 过的对话。

## 开发者向

- 改了 `lib/` 下的代码后，**必须完全退出 DSH 再启动**：宿主热重载只重建插件实例，不重新加载 JS 模块，改动不会生效。
- 判断新代码有没有生效：本包没有内置版本探针，可看插件列表里的版本号，或临时加一行日志。
- 依赖安装：工作区若是 exFAT 盘，pnpm 软链会失败，需 `--node-linker=hoisted`。
- `node_modules` 里不要放 `@deepseek-ai/*` 的副本，会遮蔽宿主自带的那份。
